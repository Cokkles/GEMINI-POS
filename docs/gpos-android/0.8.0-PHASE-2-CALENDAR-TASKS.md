# Android 0.8.0 — Phase 2 Calendar + Tasks

## Calendar

- Home Calendar cards and headings enter the named Calendar root.
- Month, week, day, and agenda views share the same canonical monthly snapshot.
- Backend 2.11.0 can return bounded primary/shared calendar sources with names,
  ownership, and colors; older backends continue to show the default calendar.
- Exact event creation includes date, start/end time, all-day mode, recent
  location suggestions, description, and an owned calendar target.
- Creation still produces a preview and requires explicit confirmation. Opening
  or refreshing Calendar never creates or changes an event.

## Tasks

- Multiple lists, list switching, new-list creation, and rename remain
  first-class.
- The editor now offers due-day and optional reminder-time pickers when
  `task_due_time_v1` is advertised.
- Google Tasks remains authoritative for the due day. Backend 2.11.0 stores the
  reminder time in a reversible AEGIS metadata marker and returns clean notes
  plus `due_time` to clients.
- Completed history remains collapsed by default and the two-minute completion
  Undo remains unchanged.

## Compatibility and rollback

- Android behavior is capability-gated against older deployed backends.
- The Android rollback is 0.7.6.1.
- The backend rollback remains 2.8.4.1; backend 2.10.0 is the immediately prior
  user-validated functional baseline.
