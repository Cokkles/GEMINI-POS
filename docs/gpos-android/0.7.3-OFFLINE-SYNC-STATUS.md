# AEGIS Android 0.7.3 Offline Sync

Status: implementation checkpoint

## Shared backend baseline

- Apps Script 2.8.0 is the additive shared-backend baseline.
- Existing Android authentication, task, follow-up, capture, Calendar, News, and HORIZON contracts remain required.

## Delivered

- Task create, edit, delete, restore, list create, and list rename actions update the encrypted local workspace first.
- Follow-up promote, dismiss, and resolve actions disappear from the active UI immediately and enter a protected account-bound queue.
- A two-minute quiet-period debounce resets whenever new queued work is staged.
- Network-constrained WorkManager processing drains mutations in creation order while the app is backgrounded.
- Manual Task sync flushes both the completion queue and the deferred mutation queue.
- Repeated edits to the same task/list are coalesced; only one pending action is retained for a follow-up.
- Non-idempotent mutations are not blindly retried after an ambiguous backend response. A failed item produces a local receipt and alert.
- Global follow-up action blocking is removed; multiple follow-ups can be handled back-to-back.

## Deliberate boundary

- Google token renewal and closed-app notification guarantees remain Android 0.7.4 and 0.7.5 work.
- Apps Script 2.8.0 does not yet certify mutation idempotency. Android therefore records ambiguous failures instead of automatically replaying them.
