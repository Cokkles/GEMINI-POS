# AEGIS Android 0.7.4.2 Device Test Checklist

1. Install 0.7.4.2 over the existing AEGIS app. Do not uninstall.
2. Confirm the installed version is `0.7.4.2-dev` (version code 18).
3. Submit one distinctive multi-item meal separated by commas.
4. Confirm the Capture page immediately reports that the meal was queued and remains usable.
5. Wait for the success/failure notification; allow up to 185 seconds for Apps Script, Gemini, and Sheets.
6. Open Nutrition and verify the meal and macros were appended once.
7. Open More → Alerts & Receipts → Recent confirmations and expand it.
8. Confirm the receipt shows `Diagnostic CONFIRMED` and an elapsed time on success.
9. If it fails, record the displayed diagnostic code and exact message before manually retrying.
10. Submit a single-item meal and confirm it also appends once.
11. Submit a Note capture and verify background capture did not regress Notes.
12. Close and reopen AEGIS while a capture is queued; confirm WorkManager finishes it or leaves an explicit diagnostic receipt.
