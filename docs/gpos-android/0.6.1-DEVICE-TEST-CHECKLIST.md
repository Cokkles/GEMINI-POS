# AEGIS Android 0.6.1 device check

Install the supplied APK over 0.6.0. The package and signer are unchanged; no uninstall or Apps Script update is required. If Android rejects the update, record the exact error before uninstalling or clearing data.

1. Home → Tasks card → Calendar tab → Tasks tab → Capture tab. Each tap opens the named page immediately, without pressing Back first.
2. More → Search → Calendar → More. More must show its menu. Capture → View confirmations & receipts → Tasks → More must also return to the named pages.
3. Tap Refresh repeatedly, then navigate while refresh runs. Confirm visible progress, responsive tabs, and eventual success or an honest cached/error state.
4. Change Calendar months rapidly. After requests settle, events must correspond to the selected month.
5. More → Settings → Show raw HORIZON text. Compare the text with the formatted HORIZON briefing, then collapse it. Checking it must not generate a new report. Backend version should report 2.7.0 if that deployment is live.
6. Restart the app and return after the Google session has aged. Previously authorized sign-in should restore/renew when Google permits it. Test a brief loss of connectivity and return online. Expiry and revoked access must not be bypassed.
7. Explicitly sign out, close/reopen the app, and verify it stays signed out. Sign back in manually when ready.
8. Spot-check the existing five-minute Task Undo queue and Calendar preview/confirmation UI. This patch adds no new write contracts.

Report the app version, exact tap sequence, expected/actual page, and any error text. Do not share tokens or credentials. Emulator checks do not replace physical-device Google OAuth, live Apps Script, Android notification, or background-service testing.
