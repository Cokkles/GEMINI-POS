## 0.6 purpose

0.6 moves AEGIS Android from broad parity toward a simpler daily-use workflow. The product rule remains:

**READ AUTOMATICALLY. MUTATE EXPLICITLY.**

Home is treated as a dashboard, not as a giant input form. High-frequency actions live on dedicated surfaces with explicit confirmation/result states.

## Shared backend baseline

The supplied current Apps Script is treated as the AEGIS backend 2.6.5 contract baseline for this checkpoint.

Android consumes existing versioned/protected contracts instead of reshaping the backend. No `Code.gs` changes were made for 0.6. Any future backend change remains a cross-client stop/review item and must be additive/backward-compatible and recorded for Android, Windows, and PWA development.

A matching shared-contract compatibility record was also written to the active AEGIS Windows development line before Android implementation proceeded.

## Daily-use Capture

Capture is a dedicated primary navigation destination rather than a large Home input block.

Primary actions are:
- Note
- Journal
- Calories
- Receipt

Secondary existing actions remain available:
- Vent
- Reflect
- Assess

All Capture submissions remain explicit foreground commands. Existing protected local receipts and Android success/failure notifications remain part of the flow.

## Google Tasks

0.6 adds native generic Task creation through the existing protected AEGIS 2.6.5 `create_task` contract when the backend advertises the feature.

Existing completion behavior remains:
- checking stages locally;
- five-minute Undo grace;
- WorkManager can flush only the user-staged completion;
- fresh canonical verification is required before a completion receipt becomes CONFIRMED;
- failure never becomes false success.

Generic Task hard-delete/edit is intentionally not invented because the supplied backend baseline does not advertise those contracts.

## News & Insights

The News workspace is simplified around:
- Headliners at the top;
- category sections collapsed by default;
- expandable story lists;
- lightweight source/time context;
- normal Android external URL handling so the configured default browser opens selected stories.

Ordinary News refresh remains read-only and does not trigger HORIZON, PRISM, or RSS generation.

## Authentication / connection state

0.6 adds a small persistent connection/auth status indicator in the app chrome.

The existing encrypted credential/session restoration path remains primary. AEGIS does not intentionally ask for Google sign-in on every launch. When stored identity material expires, Android may attempt native Credential Manager renewal before falling back to explicit sign-in.

Offline protected state remains distinct from signed-out state: connectivity loss should not be presented as logout.

## Ask AEGIS

The supplied backend 2.6.5 baseline advertises and implements `AEGIS_AI_QUERY_V1` / `ai_query`.

Android adds a native Ask AEGIS surface behind capability discovery. The interaction remains bounded/session-only and read-only from the user's perspective; it does not expose a generic mutation transport and does not claim a mutation occurred.

## Follow-ups

The supplied backend baseline includes protected Follow-up contracts. Android adds a capability-gated Follow-ups surface for:
- read current follow-ups;
- resolve;
- dismiss;
- promote to Task.

Each mutation requires explicit foreground user intent.

## Calendar

The existing simple resolve -> preview -> explicit create workflow remains available.

0.6 also exposes the backend's newer Calendar AI/confirmation path behind capability discovery. CREATE/UPDATE/DELETE proposals require preview and explicit confirmation before canonical mutation. Android does not bypass the backend's confirmation-token/replay protections.

## Home simplification and polish

Home focuses on current information and navigation rather than forms. The 0.5 device-feedback fixes remain incorporated:
- quote/attribution content-driven layout;
- human-readable canonical machine statuses;
- improved count grammar;
- null nutrition values remain unavailable instead of becoming fake zeros.
