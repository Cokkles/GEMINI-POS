## Google Tasks — primary 0.5.1 validation

Use disposable Google Tasks for this section.

### Read / refresh

- [ ] Open **Tasks** and confirm current active Google Tasks match canonical Google Tasks.
- [ ] With **no pending completion**, tap **Sync & refresh Tasks**.
- [ ] Confirm a fresh canonical Tasks read occurs and the list remains correct.
- [ ] Confirm the status message reports that canonical Google Tasks were refreshed.

### Check / Undo

- [ ] Check one disposable active task.
- [ ] Confirm it remains visible locally as **Pending** rather than disappearing immediately.
- [ ] Confirm **Undo** is available.
- [ ] Tap Undo before five minutes.
- [ ] Confirm the task returns to ordinary active state and is still active canonically.

### Check / immediate Sync

- [ ] Check a second disposable task.
- [ ] Tap **Sync & refresh Tasks** before the five-minute grace period expires.
- [ ] Confirm the queued completion is submitted immediately.
- [ ] Confirm AEGIS performs a fresh canonical verification.
- [ ] Confirm the task disappears from active Tasks only after canonical completion is verified.
- [ ] Confirm the local receipt becomes **CONFIRMED**.

### Five-minute automatic synchronization

- [ ] Check another disposable task and do not press Sync.
- [ ] Leave the app normally; wait beyond the five-minute grace period while connected.
- [ ] Confirm WorkManager eventually submits the completion.
- [ ] Reopen/refresh and confirm canonical Google Tasks reflects the completion.
- [ ] Confirm a successful Task outcome/receipt is visible.

### Offline / failure behavior

- [ ] While offline, check a disposable Task.
- [ ] Confirm it is staged locally and does not falsely claim canonical completion.
- [ ] Restore connectivity and use **Sync & refresh Tasks**, or allow bounded background synchronization.
- [ ] Confirm the task reaches CONFIRMED only after canonical verification.
- [ ] If a task ultimately fails to synchronize, confirm the failure remains visible through Alerts & Receipts.

> **Task creation is intentionally not enabled in 0.5.1.** The current shared AEGIS contracts do not expose a proven generic create-Task action. A separate additive, capability-gated shared backend contract is required before Android can safely add normal Google Tasks.
