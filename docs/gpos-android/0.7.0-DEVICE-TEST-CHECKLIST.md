# Android 0.7.0 device acceptance

Install the new APK over 0.6.1 without uninstalling. The package and development signer remain unchanged; versionCode is 12. Retain the existing app data and Google connection.

1. Home: compare borders, section accents, compact quote and HORIZON freshness. Tap the Calendar heading, event or empty state; confirm Calendar opens. Move among bottom tabs after shortcuts. Check normal and enlarged font settings.
2. Tasks: refresh and verify at least two existing lists. Switch between All lists and each list. Create a list, rename it, then create a task in that list with notes and a due date. Edit the task, remove its due date, and verify from Windows/Google Tasks. Delete a disposable task with confirmation.
3. Complete a task in the non-default list, Undo within five minutes, and verify that task remains active. Complete again and use Sync queued, or let the grace period expire in the background. Refresh: completed history should show it under its original list; Restore should return it there. Check both 7-day and 30-day filters. Refresh lists must not submit queued changes early.
4. Running Notes: type several paragraphs, wait for Saved locally, switch screens, close/reopen the app and restart the phone. The latest draft should remain. Continue editing offline. Save a checkpoint, edit again, then Restore copy; both the restored text and pre-restore recovery copy should exist. Check Copy and Android Share.
5. Explicitly sync a disposable notes section. Confirm that exactly one tagged entry appears in the canonical Notes & Ideas Log and the editor begins a fresh section. The synced section remains in recovery history. If a result is uncertain, do not repeatedly retry: inspect the journal, then explicitly mark the entry verified or retry the original section once after confirming it is absent. Autosave and ordinary refresh must never submit notes.
6. Sign out and sign back into the same account: Running Notes should stay protected locally and reopen for that account. A different account must not see that draft. Task queue and normal session data retain the established logout-clear behavior.
7. News: open Headliners settings. Deals starts off. Disable another category and verify it disappears from Home and News Headliners while remaining in its normal feed. Close/reopen the app and verify preferences persist. Expand/collapse feed sections and open stories in the default browser.
8. Recheck existing Capture, raw HORIZON Diagnostics, Calendar preview/confirm, Google session renewal, and OS navigation/keyboard insets.

Report the screen, exact action and whether the issue persists after refresh. Live backend writes in this checklist are manual device acceptance; automated tests use isolated fixtures and never mutate your production tasks or journal.
