# AEGIS Android 0.7.4 Authentication Continuity

Status: implementation checkpoint

## Shared backend baseline

- Apps Script 2.8.0 remains the additive shared-backend baseline.
- No shared backend or Windows contract is changed by this Android phase.
- AUTH-1 still verifies short-lived Google ID tokens on every protected request. Android does not extend, forge, or treat an expired token as authorization.

## Delivered

- A stored protected session exposes cached AEGIS data immediately while backend discovery and validation continue in the background; reopen no longer starts with a blocking authentication screen.
- Credential Manager requests a fresh ID token from a previously authorized Google account shortly before expiry or after AUTH-1 requests renewal.
- Silent renewal does not replace the current screen with diagnostics and does not show the interactive signing-in state.
- Periodic reads no longer delete the encrypted credential or canonical cache merely because a short-lived ID token expired.
- Task completion, deferred Task/List/Follow-up actions, and Capture retries remain encrypted and queued when authorization renewal is needed.
- A single stable system notification asks the user to open AEGIS when Android cannot renew without a foreground Activity.
- After successful renewal, AEGIS cancels the attention notification and resumes all account-matching Task, Follow-up, and Capture work.
- AUTH-1 account isolation remains enforced by deriving the queue owner from the newly issued Google token before any queued work is sent.
- Explicit Sign out remains destructive by design: it cancels background work and clears credentials, canonical cache, protected drafts, and queued private mutations.

## Android platform boundary

Google ID tokens are intentionally short-lived and cannot safely be cached indefinitely. Credential Manager renewal can be automatic for a previously authorized account, but Android requires a foreground Activity if the provider needs account selection or renewed user consent. Closed-app delivery behavior remains 0.7.5 work.
