# GPOS Android 0.4.0 — Device Test Checklist

## Install / identity

- Install 0.4.0 over the deterministic-signed 0.3.1 build.
- Confirm login/session survives the upgrade.
- Confirm Home/Today reports `GPOS Android 0.4.0-dev` when signed out or disconnected and the authenticated identity when signed in.
- Confirm no uninstall is required.

## Today dashboard

- Confirm Today opens quickly with cached or live data.
- Confirm next event matches canonical Calendar.
- Confirm today's agenda entries match the canonical dashboard.
- Confirm active task preview matches Google Tasks.
- Confirm HORIZON card reflects the current canonical briefing.
- Confirm finance purchase/credit summary matches the bounded recent-finance feed.
- Confirm active/critical server-alert count is correct.
- Tap Calendar, Tasks, HORIZON, Notifications and Finance cards and verify they navigate to the expected area.
- Tap **Sync now** and confirm all available domains refresh without clearing other domains if one fails.

## Search

- Open Search from the top-bar icon and More -> Search.
- Search for a known Calendar event title.
- Search for a known Google Task title.
- Search for a word contained in the current HORIZON briefing.
- Search for a recent finance vendor/category.
- Search for an active notification title/message.
- Confirm search is immediate and does not show a loading/network state.
- Confirm search results navigate to the correct source screen.
- Confirm offline search still works against cached data.

## Briefing

- Confirm the current HORIZON title/sections render natively.
- Tap several sections and confirm collapse/expand behavior.
- Confirm large sections remain scrollable and readable.
- Confirm Refresh briefing fetches the latest existing canonical HORIZON without generating a new briefing.

## Calendar

- Confirm Today/Tomorrow agenda matches canonical Calendar.
- Resolve a harmless test event and confirm no Calendar write occurs before Add.
- Cancel one proposal and confirm no event is created.
- Create one harmless event and confirm it appears in Google Calendar and after canonical refresh.
- Confirm cached/offline state cannot create an event.

## Tasks

- Confirm tasks are split into Scheduled and Other only from available canonical time metadata.
- Stage and unstage a task without changing Google Tasks.
- Stage a disposable task and explicitly confirm completion.
- Confirm the task is only declared complete after a fresh canonical read verifies it is absent.
- Confirm an uncertain/network failure preserves the staged selection and does not auto-retry the mutation.

## Finances

- Confirm purchase/credit totals match the current 72-hour bounded feed.
- Confirm category pulse is plausible and derived from the transactions shown.
- Confirm recent transaction vendor, amount, category, payment source and timestamps render sensibly.
- Confirm Finance remains read-only.

## Notifications

- Confirm critical/warning/info alerts are ordered with highest severity first.
- Open and leave the screen; confirm this alone does not acknowledge anything.
- Acknowledge one appropriate alert explicitly and confirm canonical refresh removes it from active alerts.
- Confirm unrelated alerts remain unchanged.

## System

- Confirm normal System screen is compact: backend, Google/auth state, sync health, background sync, notifications and appearance.
- Confirm developer OAuth/package/SHA details are hidden by default.
- Tap **Show developer diagnostics** and confirm the details appear.
- Confirm Google login remains functional.
- Confirm theme changes persist across restart.

## Offline / lifecycle

- With live data loaded, force-close GPOS and reopen it.
- Reboot the phone and reopen GPOS.
- Switch Wi-Fi -> cellular and refresh.
- Disable network and reopen; verify cached/stale labels and useful cached content.
- Confirm local Search works offline.
- Re-enable network and sync; verify domains return to LIVE independently.
- Confirm WorkManager never completes Tasks, creates Calendar events, acknowledges alerts, generates HORIZON, invokes Gemini/PRISM, refreshes RSS, or mutates finance.

## Report issues with

- screen/action;
- expected vs actual result;
- LIVE/CACHED/STALE/offline state;
- whether canonical Google/AEGIS state changed;
- visible error text;
- screenshot for layout/rendering issues.
