## Consolidated baseline

This branch is the first line that carries both the tested Android 0.7.6.1 device-session
work and the complete backend 2.10.0 nutrition identity/serving tree. The merge is deliberate:
the Android tree remains based on 0.7.6.1 while `shared-backend/` is replaced atomically by
the reviewed 2.10.0 subtree.

No deployed endpoint, OAuth client, application ID, or signing certificate changes in this
checkpoint. Existing Android clients remain compatible because backend changes are additive.

## Rollback

- Android rollback: install the signed 0.7.6.1 checkpoint APK.
- Backend rollback: redeploy the previously retained backend 2.8.4.1 script bundle.
- Source rollback points remain on their original branches; neither is rewritten or deleted.

introduced in Phase 2, and Capture/Running Notes behavior is introduced in Phase 3.
