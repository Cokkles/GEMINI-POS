# AEGIS Android 0.7.2 Daily Customization

Status: implementation checkpoint

## Delivered

- The primary bottom destination is now Notes. Running Notes remains the first, durable local scratchpad; one-time Note, Journal, Meal, and Receipt capture follows on the same scrollable page.
- Running Notes and Capture no longer occupy separate visible navigation entries. Existing `running_notes` and `capture` routes remain compatible with prior shortcuts and deep links.
- Home Google Tasks can show or hide lists with local-only switches. Visible tasks stay grouped under their list names instead of combining Grocery, Follow Ups, and unrelated work.
- Active recommended Follow-ups appear in a collapsed Home section. Promote creates a Google Task through the existing capability-gated contract; Dismiss marks the source follow-up addressed through the existing follow-up contract.
- Google Task create/edit uses the platform calendar picker. The UI accurately identifies the Google Tasks limitation: its API persists a due day, not a reminder time.
- News section order can be moved up or down and is saved locally. Headliner eligibility controls remain independent, with Deals excluded by default.
- HORIZON status and the daily quote use compact Home treatments. Ask AEGIS remains implemented but is hidden from visible navigation while its daily-use value is reassessed.

## Contract and privacy boundary

Apps Script 2.7.0 is unchanged. Task-list visibility and News order remain Android-local display preferences. Follow-up mutations use existing advertised contracts and remain explicit foreground actions.
