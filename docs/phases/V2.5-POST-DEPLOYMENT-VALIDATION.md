# HORIZON V2.5 — Post-Deployment Validation

Date: 2026-08-22
Status: PARTIAL PASS / EXIT GATES REMAIN

A fresh production briefing was generated after deployment of the V2.5 Apps Script candidate.

## Confirmed

- SPARK `STALE` state correctly omitted the reflection card.
- ACTIVE_NOTE_FILTER is working in the observed briefing: only marked `FOLLOW_UP:` items appeared; unmarked historical suggestions did not resurface.
- KINETIC bounded-state output populated the briefing.
- Calendar and intelligence sections populated.
- No legacy HORIZON JSON content appeared in the output.

## Remaining defects

- Gmail context is unavailable due to missing Apps Script Gmail authorization/scopes. The canonical query remains time-bounded (`newer_than:7d`) and explicitly not unread-only.
- The Apps Script KINETIC adapter leaks `rows_evaluated_today` into the HORIZON-facing payload; this is not part of frozen `KINETIC_TO_HORIZON_V2` and should remain internal diagnostics.
- The Apps Script currently calls `getRecentFinanceActivity(72)`, which reads/aggregates the Receipts & Expense Intake Log directly. This is not yet the intended SENTINEL-FIN authoritative-interface boundary.
- The task adapter returns an empty array on API failure, conflating `UNAVAILABLE` with verified zero active tasks. Source-status semantics must be explicit before freeze.

V2.5 must remain open until these issues are corrected and another fresh clean-room briefing passes.
