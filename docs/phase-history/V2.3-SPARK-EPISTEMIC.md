## V2.3 implementation

Implemented the SPARK evidence → epistemic classification → canonical state → bounded HORIZON projection pipeline.

Key rules:

- self-reported state accepts only `SELF_REPORTED` and `EXPLICIT_USER_INTERPRETATION`;
- `SYSTEM_HYPOTHESIS` cannot masquerade as self-report;
- current-state freshness is bounded to 48 hours;
- stale/empty/insufficient evidence yields null state instead of synthetic placeholders;
- repeated patterns require independent observations;
- raw Journal prose does not flow into HORIZON contracts;
- action candidates are advisory and have no automatic task side effects.
