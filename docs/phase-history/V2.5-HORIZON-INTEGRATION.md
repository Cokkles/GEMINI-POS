## Cutover decision

**DO NOT CLAIM PRODUCTION CUTOVER YET.**

The repository-native V2.5 consumer is implemented, but the external production HORIZON execution path is not represented by a deployable runtime target inside this repository. A controlled runtime wiring step is still required before `latest_horizon_briefing` can be regenerated through the new interface path.

This is intentional fail-closed behavior: repository implementation does not equal production deployment.
